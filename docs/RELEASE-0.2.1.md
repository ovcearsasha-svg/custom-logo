# Custom Logo 0.2.1 — исправление сборки

Сборка больше не требует пустой папки kit/runtime. При ручной загрузке файлов
через GitHub эта папка отсутствовала, и build.py завершался с FileNotFoundError
и кодом 1. Для Custom Logo содержимое этой папки не нужно.

Ошибка воспроизведена на точной копии загруженного репозитория cf314ee.
Версия повышена, чтобы Store обнаружил исправление. Исходный PNG и меню сохранены.

Это предварительный релиз исходников. Настоящий SDK/автомобиль не использовались
при проверке. Нативное меню и визуальная совместимость требуют проверки на стенде.
