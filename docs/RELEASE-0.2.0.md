# Custom Logo 0.2.0 — предварительный релиз

Статичный BMW M-логотип с нативным меню iDrive: перемещение, масштаб с сохранением
пропорций, координаты X/Y, шаг 1/5/10/20 px, показ/скрытие, сброс и сохранение.

Присланный PNG включён без изменения исходного файла. Для отображения при сборке
создаётся уменьшенная текстура; прозрачные поля и пропорции сохраняются.
Перемещение и масштаб не загружают картинку повторно. Запись настроек только по
кнопке. Есть восстановление соединения и очистка собственного слоя. HUD не включён.

Проверено локально: 7 тестов Python, 12 JavaScript на Node 24 и Node 8.16.2,
настоящий парсер каталога MGU Store, структура пакета с подставным SDK.

**Это исходники, не готовый проверенный пакет для автомобиля.** BMW SDK в релизе
нет; Store предоставляет его при сборке. Меню, автозапуск и удаление не проверены
на MGU/DKOMBI4. Установка в авто не выполнялась. Совместимость Waze проверена
по владению слоями, не визуально. Panel может скрывать штатный медиавиджет.

eDrive отключается отдельно через FDL; приложение FDL не меняет.
