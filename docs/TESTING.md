Python: PNG-фильтры, CRC, размер/тип, APNG, ограничение распаковки, alpha,
координаты, неизменность оригинала, пропорции текстуры, экран и архив.

JavaScript: официальный клиент через локальный сокет, один кадр и RGBA,
отсутствие сообщений в ожидании, reconnect, поздний renderer, waiting/shown,
отмена reconnect, независимый второй map-клиент, отказ сервера, выключение,
lifecycle/shutdown. Дополнительно: действия меню, set без повторной передачи
пикселей, масштаб/границы, сохранение и повреждённые настройки, RHMI и entrypoint.

RHMI-компоненты подставные, API взят из реального MGU App Kit. Это не визуальная
проверка BMW. Второй map-клиент — контрактная имитация, не настоящий Waze.
C++ renderer/RAMSES не запускались; его поведение проверено чтением реализации.

Подставной SDK только во временном каталоге. Архив с ним удаляется после теста
и не включается в релиз. Настоящий SDK отсутствует; сборка без него отказывает.

Не измерялись RAM/CPU/задержки MGU. Следующий этап: настоящий SDK/стенд, меню,
масштаб и сохранение, автозапуск, предупреждения/двери, Waze, режимы приборки,
медиавиджет и удаление. Подключения к автомобилю не выполнялись.
