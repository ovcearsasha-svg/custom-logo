# Установка через Store — без SSH

Это диагностическая версия: она проверяет связь с уже установленным
cluster-render и показывает результат в iDrive. Логотип на приборку не выводится.
На реальной машине установка пока не проверена.

## Установка с USB

1. Распакуйте `custom-logo-store-usb.zip` в корень флешки. Должен получиться путь
   `mgu-repo/custom-logo/mgu-repo.json`, а рядом с ним — папка `apps`.
   Сам ZIP в папку `oap` класть не нужно: это исходный репозиторий, не OAP-архив.
2. Подключите флешку к автомобилю, откройте Store и обновите список источников.
3. Найдите USB-источник `mgu-repo/custom-logo` и приложение
   **Custom Logo Diagnostics**. Нажмите установку.
4. Дождитесь окончания сборки и установки. Откройте приложение в iDrive и
   выполните ручную проверку по шагам 5–6 ниже.

Этот путь не требует GitHub или SSH. Не извлекайте флешку до окончания установки.
Для USB нужен Store, который поддерживает исходные репозитории `mgu-repo.json`.
Если приложение позже устанавливается из GitHub, Store может считать это другим
источником и предложить отдельную копию: не устанавливайте её поверх вслепую.

## Установка из GitHub

Этот вариант доступен после публикации Store-изменений в feature-ветке.
Если в ней ещё нет `mgu-repo.json`, используйте USB-архив.

1. Подключите автомобиль к интернету и откройте Store.
2. В разделе источников (Sources) добавьте GitHub-репозиторий
   `ovcearsasha-svg/custom-logo`.
3. Выберите ветку **feature/bmw-custom-logo-v0.1.0**. Не выбирайте main или
   Releases: приложение сейчас находится в feature-ветке, PR не слит.
4. Обновите список приложений и найдите **Custom Logo Diagnostics**
   (идентификатор `alx_custom_logo`). Установите его.
5. Откройте плитку **Custom Logo: диагностика** / **Custom Logo Diagnostics**
   в списке приложений iDrive. На стоящей машине нажмите **Проверить подключение**.
6. Проверка занимает не более 5 секунд. Результат и отчёт находятся на том же
   экране; длинный отчёт листается кнопками **Следующая страница** и
   **Предыдущая страница**. Сфотографируйте результат и страницы отчёта.

Названия разделов Store могут различаться по версии и языку. Для установки
нужен Store с поддержкой источников GitHub по ветке и исходных пакетов
`mgu-app.json`. Store сам использует SDK из штатного приложения автомобиля;
репозиторий не содержит BMW SDK. На ПК ничего собирать не нужно.

## Управление

- Проверка начинается только по кнопке, не при установке и не при открытии.
- **Остановить проверку** закрывает соединение. Выход с экрана тоже останавливает
  проверку; повторное открытие не запускает её снова.
- Кнопка **Language: English** / **Язык: Русский** переключает интерфейс.
- Результаты хранятся только в памяти процесса. Они не отправляются в интернет.
- Удалить приложение можно через Store. Службы и автозапуск не добавляются.

Подключение к существующему сокету может запустить сам cluster-render через его
штатную socket-activation. Приложение не создаёт слоёв, не меняет настройки,
прошивку или кодировки и не перезапускает общий сервис.

## Если что-то не получилось

| Результат | Что делать |
| --- | --- |
| Приложения нет в списке | Проверьте выбранную ветку; main пока содержит старую версию. Обновите источник. |
| Ветки или добавления источника нет | Пришлите фото экрана Store и его версии. SSH не требуется. |
| Ошибка сборки / SDK donor | Пришлите текст ошибки Store. SDK берётся из штатного приложения на MGU; не скачивайте его отдельно. |
| Сокет не найден | Проверьте в Store, что cluster-render установлен. Этот пакет его не устанавливает автоматически. |
| Нет доступа / отказ / тайм-аут | Сфотографируйте результат; не меняйте права, кодировки или прошивку. |
| Подключение проверено | Это только успешный обмен hello/status. Безопасность наложения и видимость логотипа ещё не проверены. |

В манифесте намеренно нет зависимости с минимальной версией cluster-render:
Store иначе мог бы автоматически установить или обновить общий сервис.
Приложение проверяет совместимость ответов во время ручной диагностики.
