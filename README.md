# Custom Logo 0.2.0

Статичный логотип BMW M для MGU ID7 / DKOMBI4 через существующий `cluster-render`.
Нативное меню iDrive: перемещение, размер, координаты X/Y. Предварительный релиз:
локальные тесты пройдены, установка и проверка на авто не выполнялись. HUD не включён.

## Меню

Откройте **Custom Logo** из списка приложений:

- **Вверх / вниз / влево / вправо** — перемещение.
- **Уменьшить / увеличить** — масштаб с сохранением пропорций, относительно центра.
- **Шаг** — 1, 5, 10 или 20 пикселей для перемещения и размера.
- **Показать / скрыть** — включение или отключение собственного слоя.
- **Сбросить положение и размер** — параметры из `config.json`.
- **Сохранить** — сохранить положение, размер и состояние для следующего запуска.

Вверху показаны X/Y, ширина × высота, шаг и ON/OFF. Звёздочка — несохранённые
изменения; `Saved` — сохранено; `Save failed` — запись не удалась. Без сохранения
после перезапуска возвращаются последние сохранённые параметры.

Используются стандартные RHMI-списки и кнопки, без браузера, Canvas и кадрового
таймера. Положение/масштаб меняются через `set` слоя, без повторной передачи пикселей.

## Исходный PNG не изменён

`assets/logo.png` — файл пользователя 2000×2000, байт в байт.
SHA256: `6679a78891be1afcb3721429e1985bda6668b8d85c982071816c1f7a7048f765`.
Нет обрезки, удаления фона, ретуши, перерисовки и замены цветов. Прозрачные поля
квадратного холста сохранены. При сборке создаётся текстура отображения 512×512
из-за лимитов renderer и для экономии памяти; исходник не перезаписывается.

Размер в меню относится ко всему квадратному холсту, не только к видимой букве M.
X/Y — верхний левый угол холста на `panel` 1920×720. Отрицательные координаты
позволяют вывести прозрачные поля за край экрана. По умолчанию: X=800, Y=-80,
320×320. Это пример, не калибровка eDrive. Масштаб 32–512 px. Настраивать на
неподвижном автомобиле, не перекрывая штатные предупреждения.

## Проверка и сборка

Нужны Python 3 и Node, дополнительных npm-пакетов нет:

```sh
npm test
npm run check
node tests/store-catalog.js /path/to/mgu-store
```

19 локальных тестов: 7 Python и 12 JavaScript; JavaScript повторно проверен на
Node 8.16.2. Формат каталога проверен настоящим парсером MGU Store.

Релиз содержит **исходники**, не проверенный установочный пакет. Для настоящего
пакета нужен `oap-sdk`, который Store получает из BMW-приложения. Команда
`python tools/build.py custom_logo` без SDK откажет до сборки. Подставной SDK
есть только во временном тесте; ни он, ни такой пакет не публикуются.

`mgu-repo.json` предназначен для сборки через Store. Автозапуск задан штатным
`mguAppStartType: autostart`. Полный цикл Store и меню требуют SDK/стендовой проверки.

## Ресурсы, восстановление и удаление

Пиксели отправляются один раз на соединение. Процесс остаётся подключённым:
сервер удаляет слой при отключении владельца. Официальный клиент восстанавливает
слой и пиксели после обрыва. В ожидании нет CAN-опроса и собственных записей на
накопитель. Настройки записываются только по кнопке «Сохранить».

При удалении через Store выбирается **Custom Logo**. Общий `cluster-render`
нужно оставить для Waze. Закрывается только собственное соединение, удаляется
только собственный слой. Настройки находятся в каталоге данных приложения.
FDL-кодирование eDrive не изменяется и не откатывается.

## Ограничения

Логотип не занимает map-слот Waze, не меняет FPS других клиентов, не использует
exclusive/contend/host. Визуальная совместимость с Waze ещё не подтверждена.
Сам показ `panel` может скрыть штатный медиавиджет даже при прозрачном PNG.
Нужны проверки предупреждений, режимов приборки, меню, автозапуска и удаления.

RAM/CPU и время появления картинки на MGU не измерялись. Текстура занимает
1 МиБ RGBA; клиент хранит её копию, отдельно расходуют память Node и SDK.
Отсутствие загрузок пикселей в ожидании не останавливает обычную отрисовку BMW.
